Sn0w provides a comprehensive command system accessible through the in-game chat interface. Commands allow you to control modules, manage configurations, and interact with various client features.

## Command Prefix

All commands are prefixed with a command character (typically `.` or `;` depending on your configuration).

## Available Commands

Sn0w includes the following commands:

### Core Commands

- **[bind](/reference/commands/bind)** - Bind modules to keyboard or mouse buttons
- **[config](/reference/commands/config)** - Load, save, and manage client configurations
- **[friend](/reference/commands/friend)** - Add or remove players from your friends list
- **[waypoint](/reference/commands/waypoint)** - Create and manage waypoints in the world
- **help** - Display list of all available commands
- **toggle** - Toggle modules on/off via command

### Utility Commands

- **autoregear** - Manage automatic regear functionality
- **boatkill** - Control boat killing features
- **chams** - Configure Chams rendering options
- **clearpops** - Clear totem pop tracking data
- **dupe** - Duplication-related commands
- **folder** - Open the client configuration folder
- **grab** - Grab player information
- **hclip** - Horizontal clip teleportation
- **math** - Perform mathematical calculations
- **search** - Search for blocks in the world
- **spammer** - Configure chat spammer settings
- **tp** - Teleportation commands

## Command Usage

To use a command, open the chat and type the command prefix followed by the command name and its arguments:

```
.command <arg1> <arg2> ...
```

## Getting Help

Use the `help` or `commands` command to see a list of all available commands in-game:

```
.help
```

## Command Autocomplete

Sn0w's command system includes autocomplete functionality to help you quickly enter commands and their parameters.
