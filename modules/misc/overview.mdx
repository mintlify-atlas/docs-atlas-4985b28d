## Overview

Misc modules provide various utility features that enhance gameplay but don't fit into specific combat, movement, or render categories. These modules automate common tasks and provide quality of life improvements.

## Available Modules

<CardGroup cols={2}>
  <Card title="AutoTool" icon="pickaxe" href="/modules/misc/autotool">
    Automatically switches to the best tool for breaking blocks
  </Card>
  <Card title="AutoReplenish" icon="box" href="/modules/misc/autoreplenish">
    Automatically refills items in your hotbar
  </Card>
  <Card title="FakePlayer" icon="ghost" href="/modules/misc/fakeplayer">
    Spawns a ghost player for testing
  </Card>
  <Card title="Announcer" icon="megaphone" href="/modules/misc/announcer">
    Announces your actions in chat
  </Card>
</CardGroup>

## Common Use Cases

### Automation
- **AutoTool**: Mining efficiency
- **AutoReplenish**: Continuous building/combat

### Testing & Fun
- **FakePlayer**: Test damage calculations
- **Announcer**: Server interactions
