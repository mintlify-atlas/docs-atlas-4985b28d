The Combat modules category contains powerful tools for PvP combat in Minecraft. These modules automate various combat tasks, enhance your offensive capabilities, and provide defensive utilities.

## Available Combat Modules

Sn0w includes a comprehensive suite of combat modules:

### Core Combat Modules

- **CatAura** - Advanced crystal PvP automation with placement and breaking
- **KillAura** - Automatically attacks nearby entities
- **AutoTotem** - Manages totem placement in offhand
- **AutoAnchor** - Automated respawn anchor placement and explosion
- **Criticals** - Forces critical hits on attacks
- **SelfTrap** - Surrounds yourself with obsidian for protection

### Specialized Combat Tools

- **AutoTrap** - Traps enemies in obsidian
- **AntiChainPop** - Prevents totem chain popping
- **BowAim** - Bow aimbot assistance
- **FastProjectile** - Increases projectile velocity
- **AutoXP** - Automated XP bottle throwing
- **AutoWeb** - Places webs on enemies
- **AutoMace** - Automated mace usage
- **AutoAnvil** - Drops anvils on enemies
- **Holefill** - Fills holes with obsidian
- **Catcher** - Catches players with various methods

### Anti-Modules

- **Anti32k** - Protection against 32k weapons
- **AntiHolecamp** - Prevents hole camping
- **AntiPearl** - Blocks pearl escapes
- **AntiRevert** - Prevents block revert exploits

## Combat Module Features

Most combat modules share common features:

- **Rotation Management** - Automatic head rotation to targets
- **Range Configuration** - Customizable reach and targeting ranges
- **Target Filtering** - Choose which entities to target (players, mobs, animals)
- **Anti-Cheat Compatibility** - Multiple modes to bypass different anti-cheats
- **Visual Feedback** - ESP and rendering for active targets
- **Smart Switching** - Automatic weapon/item switching

## Getting Started

1. Enable the combat modules you need from the ClickGUI
2. Configure ranges and targeting options
3. Set up rotation and timing preferences
4. Adjust anti-cheat modes based on your server
5. Practice in a safe environment before using in combat

## Important Notes

<Warning>
  Many combat modules are designed for anarchy servers and may be detected on servers with anti-cheat plugins. Always check your server's rules before using automation modules.
</Warning>

<Info>
  Combat modules work best when used together. For example, AutoTotem + CatAura + Criticals creates a powerful combination for crystal PvP.
</Info>

## Performance Tips

- Disable unused combat modules to reduce overhead
- Use "Soft" timing modes for better performance
- Adjust "Blocks Per Tick" settings to prevent lag
- Enable "Smart Delay" options to avoid packet spam
- Use rotation limits to appear more legit
