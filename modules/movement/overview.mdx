## Overview

Movement modules in Sn0w provide advanced mobility features for Minecraft, allowing you to traverse the world faster, bypass movement restrictions, and gain tactical advantages in both PvP and general gameplay.

## Available Modules

### Speed Enhancement
- **[Speed](/modules/movement/speed)** - Move around at rapid speeds with various bypass modes
- **[Flight](/modules/movement/flight)** - Fly through the air with creative or elytra-based flight modes
- **[ElytraFly](/modules/movement/elytrafly)** - Advanced elytra flight with multiple control modes and acceleration

### Tactical Movement
- **[Holesnap](/modules/movement/holesnap)** - Signature feature! Automatically snap into nearby safe holes for PvP
- **[NoSlow](/modules/movement/noslow)** - Remove slowdown effects from items, webs, and inventory actions

## Key Features

### Speed Modes
Multiple speed modes designed for different server anti-cheat systems:
- Vanilla bypass modes
- NCP (NoCheatPlus) compatible modes
- Strict server modes
- Boost and timer support

### Flight Systems
Versatile flight options for different scenarios:
- Creative-style flight with adjustable speeds
- Elytra-based flight with packet manipulation
- Anti-kick features for longer flight sessions

### Tactical Positioning
Holesnap is an **original Sn0w feature** that:
- Automatically finds nearby safe holes
- Calculates optimal path to safety
- Supports both single and double holes
- Provides visual feedback during movement

## Configuration Tips

<Tip>
For most servers, start with the default "Strafe" speed mode and "Creative" flight mode. These provide a good balance between performance and detection avoidance.
</Tip>

<Warning>
Using aggressive speed or flight settings (especially with timer modifications) can trigger anti-cheat systems. Always test settings on lower values first.
</Warning>

## Common Use Cases

### PvP Combat
- Use **Holesnap** to quickly retreat to safe positions
- Enable **NoSlow** to maintain mobility while using items
- Configure **Speed** with boost for fast repositioning

### Travel & Exploration
- **ElytraFly** Factor mode for long-distance travel
- **Flight** Creative mode for building and terraforming
- **Speed** Vanilla mode for safe, fast ground movement

### Elytra Combat
- **ElytraFly** Control or Bounce modes for aerial combat
- Enable firework boost for aggressive plays
- Use highway dodge for obstacle avoidance
