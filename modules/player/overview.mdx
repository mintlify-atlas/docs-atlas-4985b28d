## Overview

Player modules modify and enhance player actions, from block placement to mining speed. These modules provide quality of life improvements and competitive advantages in various gameplay scenarios.

## Available Modules

<CardGroup cols={2}>
  <Card title="Scaffold" icon="cubes" href="/modules/player/scaffold">
    Automatically places blocks beneath you while moving
  </Card>
  <Card title="FastPlace" icon="hand-pointer" href="/modules/player/fastplace">
    Use and place items faster than normal
  </Card>
  <Card title="SpeedMine" icon="hammer" href="/modules/player/speedmine">
    Break blocks faster in various modes
  </Card>
</CardGroup>

## Module Categories

<AccordionGroup>
  <Accordion title="Building & Placement">
    **Scaffold** - Essential for bridging and building
    - Automatic block placement below you
    - Tower mode for vertical building
    - SafeWalk to prevent falling
    
    **FastPlace** - Accelerated item usage
    - Fast block placement
    - Fast XP bottle throwing
    - Fast bow shooting
  </Accordion>
  
  <Accordion title="Mining & Breaking">
    **SpeedMine (Nuker)** - Mass block breaking
    - Multiple mining modes
    - Automatic tool selection with AutoTool
    - Large area coverage
  </Accordion>
</AccordionGroup>

## Common Use Cases

### PvP Combat
- **Scaffold**: Quick cover and escape routes
- **FastPlace**: Rapid crystal placement
- **SpeedMine**: Breaking opponent's barriers

### Building Projects
- **Scaffold**: Large-scale bridging
- **FastPlace**: Faster construction
- **SpeedMine**: Terrain clearing

### Survival Gameplay
- **Scaffold**: Safe mining and exploration
- **FastPlace**: Efficient farming
- **SpeedMine**: Resource gathering

## Getting Started

<Steps>
  <Step title="Choose Your Module">
    Select the module based on your current task:
    - Building? Use Scaffold + FastPlace
    - Mining? Use SpeedMine + AutoTool
    - PvP? Use all three for maximum advantage
  </Step>
  
  <Step title="Configure Settings">
    Each module has specific settings to optimize for your playstyle and server anti-cheat
  </Step>
  
  <Step title="Practice">
    Test in a safe environment before using in critical situations
  </Step>
</Steps>

<Info>
  Many player modules work best when combined. For example, Scaffold + FastPlace + SafeWalk creates a powerful building setup.
</Info>
